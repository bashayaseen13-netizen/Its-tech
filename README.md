# Its-tech — Editorial Research Engine

Source-first technology publication system.

## Phase 1
- Research dossier workflow
- Source comparison
- Agreement/disagreement tracking
- Information gaps
- Original editorial angles
- Article drafting from the research dossier

## Development
This repository is being built in phases. Live web retrieval, evidence mapping, contradiction detection, editorial QA, SEO and publishing automation will be added in later phases.
